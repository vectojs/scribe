# Security Policy

## Supported Versions

Only the latest `main` is supported with security updates.

## Reporting a Vulnerability

Email `security@vectojs.org` with a description, reproduction, and impact. Do not open a public issue for undisclosed vulnerabilities. We aim to acknowledge within 72 hours.

## Scope

This policy covers `scribe` (the Scribe editor app). Dependency vulnerabilities in `@vectojs/*` should be reported to the main `vectojs` repository.
